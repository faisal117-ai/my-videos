# Urdu films: Hindi title and description

YouTube Studio → the video → **Subtitles** (or Translations) → **Add language** → **Hindi** → **Title & description**
→ paste → Publish. Hindi-language viewers then see the title in Devanagari; the audio stays Urdu, which Hindi
speakers understand. (No Quran translation in Hindi is quoted here: the package has none.)

## EP 1: Hazrat Musa (https://youtu.be/h59TV5hdSew)
**Title**
```
क़सस-उल-अंबिया EP 1: हज़रत मूसा (अ.स.) और फ़िरऔन का मुकम्मल वाक़िया | फ़ुल मूवी उर्दू/हिंदी
```
**Description**
```
क़ुरआन से हज़रत मूसा (अ.स.) का मुकम्मल वाक़िया: दरिया में संदूक़, मदयन का कुआँ, पहाड़ पर आग, जादूगर, समुंदर का फटना और फ़िरऔन का अंजाम।

एनिमेशन; हर आयत हवाले के साथ स्क्रीन पर। किसी नबी को किसी भी शक्ल में नहीं दिखाया गया।
Haq Stories | حق کہانیاں को सब्सक्राइब करें, क़ुरआन से नबियों के क़िस्सों के लिए।
```
